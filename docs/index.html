DEPLOYMENT DOCUMENTATION

ProCDN

Hướng dẫn triển khai CDN trên Cloudflare bằng Dashboard, cấu hình D1, KV và thiết lập tài khoản quản trị.

Bắt đầu

ProCDN cung cấp CDN cho tài nguyên từ GitHub và các nguồn tùy chỉnh, sử dụng Cloudflare Workers để xử lý request và cache.

Trước khi bắt đầu, cần có tài khoản Cloudflare và source code ProCDN đã được chuẩn bị để deploy.

Mở Cloudflare Dashboard ↗

Tên binding phải khớp chính xác với code: D1 dùng db, KV dùng kv.

1Tạo D1 Database

  1. Mở Cloudflare Dashboard.
  2. Vào Storage & databases → D1 SQL Database.
  3. Chọn Create database.
  4. Đặt tên, ví dụ procdn-db.
  5. Nhấn Create để hoàn tất.

D1 lưu dữ liệu quản trị và các dữ liệu có cấu trúc của ứng dụng.

2Khởi tạo schema database

  1. Mở database vừa tạo.
  2. Mở file migrations/0001_init.sql trong source ProCDN.
  3. Sao chép nội dung SQL.
  4. Dán vào mục Console/SQL Console của D1 và chạy truy vấn.
  5. Kiểm tra các bảng đã được tạo thành công.
Chỉ chạy SQL schema đúng với phiên bản source đang dùng. Không chạy lại các câu lệnh phá hủy dữ liệu trên database đang hoạt động.

3Tạo KV Namespace

  1. Trong Cloudflare Dashboard, mở Storage & databases → Workers KV.
  2. Chọn tạo namespace mới.
  3. Đặt tên, ví dụ procdn-kv.
  4. Nhấn Create.

KV dùng để lưu dữ liệu key/value phù hợp với thiết kế ứng dụng. Không dùng KV thay thế cho các truy vấn quan hệ của D1.

4Deploy Worker

  1. Mở Workers & Pages.
  2. Chọn tạo Worker mới hoặc mở Worker ProCDN đã có.
  3. Tải lên hoặc triển khai source theo phương thức được dự án hỗ trợ.
  4. Đặt tên Worker, ví dụ procdn.
  5. Kiểm tra entry point và cấu hình tương thích với Cloudflare Workers.
Không phải mọi dự án đều có thể deploy chỉ bằng cách tải một file JavaScript lên Dashboard. Nếu source dùng npm packages, module imports hoặc bước build, cần build source theo hướng dẫn của dự án trước.

5Thêm D1 Binding

  1. Mở Worker ProCDN.
  2. Vào Settings → Bindings.
  3. Chọn Add binding → D1 database.
  4. Variable name nhập db.
  5. Ở phần database, chọn procdn-db hoặc database của người dùng.
  6. Lưu cấu hình.

Code truy cập binding bằng env.db.

6Thêm KV Binding

  1. Trong cùng trang Settings → Bindings, chọn Add binding.
  2. Chọn loại KV namespace.
  3. Variable name nhập kv.
  4. Chọn namespace đã tạo ở bước 3.
  5. Lưu cấu hình.

Code truy cập binding bằng env.kv.

7Cấu hình SESSION_SECRET

  1. Trong Worker, mở Settings → Variables and Secrets hoặc mục cấu hình biến tương ứng trên Dashboard.
  2. Thêm secret có tên SESSION_SECRET.
  3. Dùng một chuỗi ngẫu nhiên dài, bí mật và khó đoán.
  4. Lưu secret rồi deploy lại nếu Dashboard yêu cầu.
Không đưa SESSION_SECRET vào mã frontend, GitHub công khai hoặc file JavaScript được phân phối qua CDN. File .env trên máy local không tự động được áp dụng vào Worker production.

8Tạo tài khoản quản trị

  1. Mở URL Worker sau khi deploy.
  2. Nếu chưa có tài khoản quản trị, trang setup sẽ yêu cầu tạo username và password.
  3. Hoàn tất setup và đăng nhập.
  4. Sau khi tạo quản trị viên, trang setup cần bị khóa để tránh người khác chiếm quyền.
Chỉ tạo tài khoản trên website sau khi đã cấu hình D1 binding và khởi tạo schema thành công.

9Kiểm tra CDN

Ví dụ URL GitHub CDN theo định dạng ProCDN:

/gh/OWNER/REPO@VERSION/path/to/file.js

Thay OWNER, REPO, VERSION và đường dẫn bằng tài nguyên có thật trong một repository GitHub công khai.

Kiểm tra:

  • File trả về đúng nội dung và Content-Type.
  • Đường dẫn không tồn tại trả về lỗi phù hợp.
  • Header cache phản ánh đúng trạng thái HIT/MISS nếu tính năng này đã được triển khai.
  • Các trang quản trị yêu cầu đăng nhập.

Xử lý lỗi thường gặp

Thiếu binding db hoặc kv

Kiểm tra tên biến binding và tài nguyên được chọn trong Settings → Bindings.

Thiếu bảng trong D1

Kiểm tra đã chạy file migration đúng phiên bản trên đúng database chưa.

Trang setup hoặc đăng nhập lỗi

Kiểm tra D1 binding, schema, SESSION_SECRET và log của Worker.

Deploy lỗi

Kiểm tra entry point, dependencies và hướng dẫn build trong README của source ProCDN.

Checklist trước khi sử dụng

  • D1 đã tạo và schema đã được khởi tạo.
  • KV namespace đã tạo.
  • D1 binding tên db đã được thêm.
  • KV binding tên kv đã được thêm.
  • SESSION_SECRET đã được cấu hình an toàn.
  • Worker đã deploy thành công.
  • Tài khoản quản trị đầu tiên đã được tạo.
  • Đã kiểm thử CDN, cache và trang quản trị.
